# 在线抽号系统

一个用于课堂随机抽取小组发言的网页工具，解决人工点名遗漏导致的不公平问题。

## 功能

- **参数设置**：设置总小组数和每次抽取组数。
- **抽号动效**：点击抽号后，数字快速滚动约 1.2 秒，随后定格结果。
- **庆祝动画**：结果弹出时触发彩带飘落和放大闪烁效果。
- **防重复机制**：已抽中的小组自动排除，界面实时展示剩余未抽取组号。
- **重置功能**：一键重置，清空记录开始新一轮抽号。

## 使用方式

1. 使用浏览器直接打开 `index.html` 即可运行。
2. 输入总小组数和每次抽取组数，点击“开始抽号”。
3. 抽号结束后，界面中央会显示抽中的小组号码。
4. 点击“重置”可清空记录并开始新一轮。

## 文件说明

- `index.html`：页面结构
- `styles.css`：样式与动画
- `script.js`：抽号逻辑与交互

## 依赖

- Tailwind CSS（通过 CDN 引入）
- Canvas Confetti（通过 CDN 引入）
