# 在线抽号系统

一个用于课堂随机抽取小组发言的网页工具，解决人工点名遗漏导致的不公平问题。
**抽样在数学上严格等概率，结果可事后复核。**

## 功能

- **参数设置**：设置总小组数和每次抽取组数（1–999）。
- **抽号动效**：点击抽号后数字快速滚动约 1.2 秒，随后定格结果。
- **减少动态效果**：系统开启「减少动态效果」时自动缩短动画。
- **庆祝动画**：结果弹出时触发彩带飘落和放大闪烁效果（纯装饰，失败不影响抽号）。
- **防重复机制**：已抽中的小组自动排除，界面实时展示剩余未抽取组号。
- **记录保护**：修改总小组数不会无条件清空已抽记录，只清理超出新范围的号码并要求确认。
- **可核验日志**：每次抽号记录随机种子与抽样前后的号码池，可导出 JSON，任何人可离线复算。
- **重置功能**：一键重置，清空记录开始新一轮抽号。

## 公平性是怎么保证的

1. **熵源**：优先使用 `crypto.getRandomValues()`（操作系统级 CSPRNG）；
   不可用时才降级到 `Math.random()` 并在控制台显式告警，绝不静默降级。
2. **零取模偏差**：用**拒绝采样**把 2³² 个样本切成整数倍区间，超出部分丢弃重抽，
   每个取值对应的样本数完全相同。
3. **无放回等概率**：抽样采用**部分 Fisher-Yates**，第 i 次从剩余 n−i 个号码中均匀取 1 个，
   因此每个组合被抽中的概率恒为 1/C(n,k)。
4. **先定后演**：结果在点击「开始抽号」的瞬间就已确定，1.2 秒动画只负责揭晓，
   绝不参与决策，也绝不读取屏幕上显示的数字。
5. **冻结参数**：抽号过程中参数输入框被禁用，杜绝「动画期间改参数污染结果」。
6. **可复核**：每条记录都带 128 位种子，用同样的抽样函数即可离线重算出同一结果；
   记录之间用 SHA-256 哈希链连接，事后删改任意一条都会断链。

## 如何核验一次抽取

1. 点击页面底部「导出记录」，得到 `抽号记录-*.json`。
2. 对任意一条记录，用它的 `seed` 重建随机发生器，按 `poolBefore` 重跑抽样：

   ```js
   const rng = FairRandom.makeSeededRandInt(FairRandom.seedHexToU32(record.seed));
   const re = FairRandom.sampleWithoutReplacement(record.poolBefore, record.selected.length, rng);
   // re.selected 应与 record.selected 完全一致，re.pool 应与 record.poolAfter 完全一致
   ```

3. 在页面控制台也可一键复核：

   ```js
   LotteryAudit.verifyAll();   // 所有记录是否都能用种子复算出来
   LotteryAudit.getLog();      // 查看原始记录
   ```

> 诚实边界：纯前端页面无法做到密码学意义上的不可抵赖。
> 日志的作用是让**正常流程可复核**、并显著提高篡改成本。
> 若用于正式比赛，建议课前把「抽号记录」或录像留证，或引入第三方随机信标。

## 使用方式

1. 直接双击 `index.html` 用浏览器打开即可运行；也可用本地服务：
   ```bash
   python3 -m http.server 8080   # 然后访问 http://127.0.0.1:8080/
   ```
2. 输入总小组数和每次抽取组数，点击「开始抽号」。
3. 抽号结束后，界面中央会显示抽中的小组号码。
4. 点击「重置」可清空记录并开始新一轮。

## 文件说明

- `index.html`：页面结构
- `styles.css`：样式与动画
- `random.js`：**公平抽样核心**（crypto + 拒绝采样 + 种子化 sfc32 + 部分 Fisher-Yates），可独立审计
- `script.js`：界面逻辑、状态管理、抽取日志
- `tests/randomness-test.mjs`：随机性与公平性的统计检验（Node 直接运行）

## 自测

```bash
node tests/randomness-test.mjs
```

会执行卡方均匀性检验（单次抽取、批量抽取、全部抽完的顺序均匀性）、
单次内部不重复检查、种子可复现性与防篡改检查。

## 依赖

- 运行时**无必需依赖**，离线可用。
- Canvas Confetti（可选，CDN 异步加载）：仅用于庆祝彩带，加载失败不影响抽号。
- Google Fonts（可选）：字体加载失败时回退到系统字体。
